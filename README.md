# 🏝️ J-Tour - Jogja Tour Planner
### Merencanakan Liburan Jogja Menjadi Lebih Mudah dan Terstruktur

Aplikasi desktop berbasis **Java** dan **JavaFX** untuk membantu wisatawan menyusun itinerary perjalanan wisata di Yogyakarta secara efektif.

---

# 📖 Tentang Project

J-Tour (Jogja Tour Planner) merupakan aplikasi desktop yang dikembangkan untuk membantu wisatawan menyusun rencana perjalanan wisata di Kota Yogyakarta.

Aplikasi ini hadir sebagai solusi bagi pengguna yang sering mengalami kesulitan ketika harus:

- Mencari destinasi wisata dari berbagai sumber.
- Menentukan urutan perjalanan harian.
- Mencatat itinerary secara manual.
- Mengelompokkan destinasi berdasarkan kategori wisata.

Melalui J-Tour, seluruh proses tersebut dapat dilakukan dalam satu aplikasi yang sederhana dan mudah digunakan.

---

# 🎯 Tujuan Aplikasi

- Membantu pengguna merencanakan perjalanan wisata.
- Menyusun itinerary harian secara terstruktur.
- Memperkenalkan berbagai destinasi wisata Jogja.
- Mengoptimalkan waktu liburan pengguna.
- Menjadi media informasi wisata yang mudah diakses.

---

# 👥 Role Sistem

J-Tour memiliki dua jenis pengguna:

## 🧑 User

Pengguna yang menyusun rencana perjalanan wisata.

Fitur:

- Registrasi akun
- Login
- Manajemen profil
- Pencarian destinasi
- Filter kategori wisata
- Penyusunan itinerary harian
- Penyimpanan itinerary
- Ringkasan seluruh perjalanan

---

## 👨‍💼 Admin

Pengelola data destinasi wisata.

Fitur:

- Login admin
- Tambah destinasi
- Edit destinasi
- Hapus destinasi
- Manajemen katalog wisata

---


---

# ✨ Fitur Utama

## 📅 Trip Planner

- Menentukan jumlah hari perjalanan.
- Menambahkan destinasi ke hari tertentu.
- Menyusun perjalanan hingga beberapa hari.

---

## 🔍 Search Destinasi

Memudahkan pengguna menemukan destinasi tertentu berdasarkan nama.

---

## 🏷️ Filter Kategori

Kategori yang tersedia:

- Alam
- Budaya
- Hiburan
- Kuliner
- Museum
- Belanja

---

## 📋 Ringkasan Itinerary

Menampilkan seluruh jadwal perjalanan dari hari pertama hingga hari terakhir.

---

## ⚙️ Pengaturan Profil

Pengguna dapat:

- Mengubah password
- Menghapus akun

---

## 🗂️ Manajemen Destinasi

Admin dapat:

- Menambahkan destinasi baru
- Memperbarui informasi destinasi
- Menghapus destinasi
